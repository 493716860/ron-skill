# api-database-design V1.0
企业级 API 与数据库详细设计 Skill。输入产品需求设计成果，输出可直接指导 Go + Gin 后端及两个前端实现的技术设计包。
## 核心产物
- api/openapi.yaml：OpenAPI 3.1 契约权威来源
- database/*.sql：MySQL 8.4 LTS 版本化 Migration
- database/data-dictionary.md：字段字典
- design/transaction.md、state-machine.md、permissions.md、traceability.md：技术规则和需求追踪
## 使用
本目录可独立下载；开发前必须人工确认高风险规则及设计状态。技术设计不替代已确认业务需求，编码仍遵守各工程 Skill。
